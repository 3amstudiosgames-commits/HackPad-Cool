# HackPad-Cool
A 9 switch, 9 LED, 1 rotary switch macropad powered by MOUDLE-SEEEDUINO-XIAO with a 3D printing case.
## Features:
3d printed case, 9 keys, 9 LED, 1 rotary encoder, 1 Seeed XIAO RP2040 + coded keys
## BOM/ bill of materials:
- 1 unsoldered Seeed XIAO RP2040
- 9x through-hole 1N4148 Diodes
- 9x MX-Style switches
- 1x EC11E Rotary encoders (with switch!)
- 9x white blank DSA keycaps
- 16x SK6812 MINI-E LEDs
- 6x M3x16mm screws
- 6x M3x5mx4mm heatset inserts
- Soldering iron
- 3D printing case
- pcb
(for more information go to BOM.csv)

## How I Made This:
- Started with the schematic and assigned footprints based on approved parts.  
- Created a PCB from the schmatic's information and footprint.  
- Wired everything  
- Generated a plate in  ai03's plate generator.  
- Downloaded Step file of PCB and the plate that was generated into Fusion 360.  
- Modeled the case based on height and width of the PCB (+0.4 to prevent the 3D case from shrinking to much)
- Checked the size with the PCB
- Added the plate to do the top part of the case.
- Downloaded the top and bottom part separate.
- Worked on getting all files necessary for GitHub
